_______________________________________________________________
This project is a code for simulating heat on a flat plane of a selected material.
_______________________________________________________________

Main4 contains the equaitions and runs the simluation, displaying it as text.

Sim2 contains the settings for the simulation

The heat zone that it is simulating is a 30 by 30 grid.


_______________________________________________________________
Any setting file you make should be set up like the following.
_______________________________________________________________
file name

coordinates

number of cycles

refresh Rate


_______________________________________________________________
Explanation of the veriables.
_______________________________________________________________
fileName: name of the file

coordinates: how big the surface is

numOfCycles: how many times it will run the equation for heat dispersion

refreshRate: how often the screen will show the heat traveling
